# Harshit Bhardwaj Portfolio

React + TypeScript rider-themed portfolio for Harshit Bhardwaj.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Main files

- `src/App.tsx` contains the typed React components and portfolio content.
- `src/styles.css` contains the rider garage visual system.
- `index.html` is the Vite entry document.
